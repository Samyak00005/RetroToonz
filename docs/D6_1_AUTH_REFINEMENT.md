# D6.1 — Auth refinement

This refinement keeps the D6 account architecture while restoring the preferred auth personality.

## Changes
- Slow-moving background doodles are back on Login/Signup/Forgot Password.
- Decorative triangle/square/wave elements float subtly instead of remaining completely static.
- Forgot Password is placed below the password field, where users expect a recovery action.
- Auth primary buttons use the RetroToonz cyan-to-blue brand direction with white copy, subtle depth, and restrained hover/press motion.

## Motion
The animation is intentionally slow and low-opacity and is disabled by the global `prefers-reduced-motion` handling.
