# RetroToonz Design Token Map

| Role | Token |
|---|---|
| Page background | `--rt-bg` |
| Elevated background | `--rt-bg-elevated` |
| Soft background | `--rt-bg-soft` |
| Standard surface | `--rt-surface` |
| Elevated surface | `--rt-surface-elevated` |
| Standard border | `--rt-border` |
| Strong border | `--rt-border-strong` |
| Primary text | `--rt-text` |
| Secondary text | `--rt-text-soft` |
| Muted text | `--rt-text-muted` |
| Brand | `--rt-brand` |
| Strong brand | `--rt-brand-strong` |
| Accent | `--rt-accent` |
| Danger | `--rt-danger` |
| Success | `--rt-success` |
| Public page gutter | `--rt-page-gutter` |
| Section rhythm | `--rt-section-gap` |
| Control radius | `--rt-radius-control` |
| Card radius | `--rt-radius-card` |
| Panel radius | `--rt-radius-panel` |
| Standard motion | `--rt-motion-base` |
| Standard easing | `--rt-ease-standard` |

New page work should prefer these tokens or the shared `rt-*` primitives instead of adding isolated values.
